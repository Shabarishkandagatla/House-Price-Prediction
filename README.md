# California House Price Prediction

## Project Overview
A Machine Learning project that predicts California house prices using Random Forest Regression.

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Streamlit
- Joblib
- Matplotlib

## Model
Random Forest Regressor

## Evaluation
- R² Score: 0.817
- MAE: ~31636

## Features
- Data preprocessing
- Missing value handling
- One-hot encoding
- Random Forest Regression
- Streamlit web application

## Run

pip install -r requirements.txt

python train.py

streamlit run app.py
